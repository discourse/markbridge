## Start with a conversion

```ruby
require "markbridge/bbcode"

result = Markbridge.bbcode_to_markdown(
  "[b]Hello[/b] [url=https://example.com]world[/url]!"
)

result.markdown # => "**Hello** [world](https://example.com)!"
```

The shipped renderer produces **Discourse-flavored Markdown**. The parsers and AST are independent of the renderer, so you can use the same parsed content for your own output format.

## From markup to Markdown

<Steps>

1. **Parse your input.** Each parser builds the same kind of AST.
2. **Inspect or edit the AST.** Your code can change nodes before normalization prepares them for Markdown.
3. **Render the result.** Use the Discourse renderer or write your own renderer for the shared AST.

</Steps>

Read the [architecture guide](/concepts/architecture/) for the details.
