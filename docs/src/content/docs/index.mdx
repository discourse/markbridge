## Start with a conversion

```ruby
require "markbridge/bbcode"

result = Markbridge.bbcode_to_markdown(
  "[b]Hello[/b] [url=https://example.com]world[/url]!"
)

result.markdown # => "**Hello** [world](https://example.com)!"
```

The renderer that ships with Markbridge writes Markdown for Discourse. The parsers and the AST do not depend on it, so you can use the parsed content for your own output format.

## From markup to Markdown

<Steps>

1. **Parse your input.** Every parser builds the same kind of tree, the AST.
2. **Look at the AST or change it.** Your code gets the tree before Markbridge rewrites what Markdown cannot nest.
3. **Render the result.** Use the Discourse renderer, or write your own renderer for the same tree.

</Steps>

Read the [architecture guide](/concepts/architecture/) for the details.

## Migrating to Discourse

Markbridge converts the posts and counts the tags it did not know. Uploads, users and internal links stay in your hands: you get them as nodes of the tree and resolve them in your importer. The migration guide explains how the parts work together.
